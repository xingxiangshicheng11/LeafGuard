# 项目总结（经验、改进、思政）

本文件用于论文/汇报的"总结"部分，内容基于本项目的真实实验与工程实践。

## 1. 经验总结
- **迁移学习有效**：在 132 类任务上，微调（E3/E4）在内部 val 与 **PlantDoc 真实场景外部**均显著优于从零/冻结（E1/E2）。外部 Macro-F1 从 ~0.20 提升到 ~0.33，Acc 从 ~0.18 到 ~0.32。
- **冻结不如微调**：仅训练分类头（E2）在小样本/多类别下欠拟合，未充分发挥预训练价值。
- **数据划分决定可信度**：采用 leaf-aware 分组划分（近重复整组进同一 split）避免泄漏；PlantWild 训练前去重。若用普通随机划分，评估会偏乐观。
- **域差异是落地最大障碍**：内部 ~89–93% 的准确率在真实 PlantDoc 上降到 18–32%；其中"健康"类最脆弱（外部 F1≈0），同作物内的相似病害（玉米两种叶斑、番茄/马铃薯疫病）最易混。
- **工程与复现同样重要**：固定种子、幂等编排（可断点续跑）、CI、统一 checkpoint 字段与接口合同，是长实验能稳定推进、结果可复核的前提。
- **不确定性与合规**：对超纲图加 OOD 拒识，避免"错误又自信"；严格遵守数据许可（PlantWild CC BY-NC-ND、PlantDoc CC BY 4.0），数据不入库。

## 2. 改进思路
- **缩小域差异**：推理端去背景/裁剪叶片、测试时增强（TTA）；引入真实场景训练数据或做域适应。
- **类别不均衡与易混**：类权重/重采样；针对易混类别对做针对性增强或引入更细粒度特征。
- **不确定性建模**：在现有 MSP+energy 拒识基础上，加入温度标定/特征距离，低置信时不给处置建议，明确"需人工确诊"。
- **更强模型**：ResNet50 / EfficientNet / ViT，或知识蒸馏；在显存允许下尝试更大输入分辨率。
- **评估更全面**：外部评估扩展到 PlantWild 专有类、增加更多真实网图；对健康/病害二分类与细粒度分类分别评估。
- **产品化**：网页 Demo 增加置信度提示与拒识说明；提供批量筛查与可疑样本导出，便于人工复核。

## 3. 思政
- **科技助农、服务乡村振兴**：以 AI 辅助植物病害早筛，助力粮食安全与农业现代化，体现科技服务国家战略与民生需求。
- **实事求是、学术诚信**：如实报告真实运行指标，不夸大、不把他人的论文数字当作本项目结果；引用真实文献并标注来源。
- **负责任的 AI**：正视模型的域差异与误判风险，明确"仅辅助、需人工确诊"，对不确定结果主动拒识，避免误导用药。
- **数据合规与知识产权**：遵守数据集许可（非商业、禁止演绎等），标注来源与引用，不擅自传播数据。
- **团队协作与工匠精神**：通过 Git 分支/PR/CI、明确分工、可复现实验流程，培养规范、严谨、可持续的工程习惯。
