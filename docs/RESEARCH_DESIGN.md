# 研究设计

题目：基于迁移学习的植物叶片病害识别与泛化能力研究。

研究问题：预训练 ResNet18 是否优于从零训练 CNN？数据增强是否改善表现？自然背景外部数据上性能下降多少？哪些类别易混淆？

实验：E1 SmallCNN；E2 冻结 ResNet18；E3 微调 ResNet18 layer4；E4 ResNet18 + 轻量增强；E5（可选）PlantDoc 共同类别外部评估。

主数据集 PlantVillage，常见版本约 54,000 张、38 类，实际以本地扫描为准。按类分层 70/15/15，seed=42。PlantDoc 默认仅作外部评估，先人工审核类别映射。

指标：Accuracy、Macro-F1、Macro Recall、混淆矩阵、训练时间。泛化差距可定义为内部测试 Macro-F1 减外部测试 Macro-F1，但需讨论数据集差异。

限制：背景、类别分布、图像质量、标签定义均可能影响跨数据集结果；结论必须由真实实验支持。
